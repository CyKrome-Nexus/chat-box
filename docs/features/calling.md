# Audio & Video Calling Documentation

## Overview
Covers carrier-grade VoIP and video calling:
- **Native Lock Screen UI**: Apple CallKit & PushKit VoIP integration; Android TelecomManager and full-screen incoming intent.
- **Audio Pipeline**: WebRTC Opus codec with automatic proximity sensor routing (earpiece vs speakerphone).
- **Video Calling**: 1-on-1 and multi-party video grids with floating Picture-in-Picture (PiP).
- **Call Management**: Persistent call logs and missed call badges.
