# Ephemeral Stories & Status Updates

## Overview
Covers 24-hour ephemeral status updates:
- **Story Player**: Segmented progress bars with tap/hold navigation.
- **Story Creator**: Photo/video capture with captions, stickers, and text gradients.
- **Privacy & Receipts**: "My Contacts", "My Contacts Except...", and "Only Share With..." with real-time viewer tracking.
- **Auto-Expiry**: 24-hour automatic purge of media from CDN and object storage.
